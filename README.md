# 🎭 The Living Muse

> *A collaborative creative sanctuary where AI bridges the gap between how we see ourselves and how we feel.*

The Living Muse is a **multi-modal, AI-native poetry platform** that transforms photos into stylized "Orchid Muse" avatars, generates emotionally adaptive poetry, and performs it with synchronized lip-sync, background music, and conversational verse — all in real time.

It isn't just a tool that "makes" poetry — it's a **digital mirror** and **artistic co-creator** that helps poets find a visual and aural voice for their words.

---

## ✨ Core Features

| Feature | Description |
|---------|-------------|
| **Orchid Avatar Creator** | Transforms photos into stylized "Orchid Muse" avatars using Nano Banana (Gemini 3 Pro Image) |
| **Syllabic Syncing** | Real-time lip-syncing where the avatar "performs" the generated poem |
| **Conversational Verse** | "Live Mode" — speak a line, and the Muse speaks back in rhyme |
| **The Gallery** | Personal library of "Living Pages" stored as interactive digital files |
| **Social Export** | One-click export as high-fidelity 4K video for social sharing |
| **The Living Book** | Exportable, printable 10-poem collection as a premium digital file |

---

## 🧠 AI Stack

| Model | Purpose |
|-------|---------|
| **Gemini 3.1 Pro** | Poetry generation, sentiment analysis, conversational verse logic |
| **Nano Banana (Gemini 3 Pro Image)** | Photo → Orchid Muse avatar stylization |
| **Veo 3** | Avatar performance video generation with lip-sync |
| **Lyria 3** | Background music generation matched to poem mood |
| **Vertex AI** | Orchestration, model serving, and infrastructure |

## 🎯 Target Audience

- **The Aspiring Poet** — Writers seeking a multimedia edge for their first published collection
- **Social Creatives** — TikTok/Instagram users wanting high-art, stylized content beyond generic filters
- **Digital Collectors** — People interested in "Living Art" and personalized digital mementos
